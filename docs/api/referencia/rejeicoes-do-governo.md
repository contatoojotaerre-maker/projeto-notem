# Rejeições do governo

Quando o governo recusa uma emissão, um cancelamento ou uma substituição, a resposta é `422 REJEITADO_GOVERNO`. Cada item de `erro.detalhes` traz o código original (`codigo_governo`), a mensagem original (`mensagem_governo`), o `complemento` e, quando a notem conhece o código, a explicação em português na `mensagem` e o `campo` a corrigir.

A tabela abaixo lista os códigos que a notem explica. Os detalhes preservam código, mensagem e complemento originais do governo; a explicação em português não os substitui.
