# Referência da API

Cada operação tem uma página com método e endereço, parâmetros, corpo com todos os campos, respostas por status e exemplos em cURL e JavaScript. Os exemplos usam somente dados fictícios.

- Endereço base: `https://app.notemfiscal.com.br/api/v1`
- Autenticação: `Authorization: Bearer {chave}` em todas as chamadas. Veja [Autenticação](../primeiros-passos/autenticacao.md).
- Erros: sempre no formato descrito em [Erros](../primeiros-passos/erros.md).
- Especificação completa para ferramentas (OpenAPI 3.1): [openapi.yaml](../openapi.yaml).
