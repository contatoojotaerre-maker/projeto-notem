# DANFSe E2 — comparação visual

PNGs: modelo, homologacao, cancelada, substituida, canhoto, estrangeiro e desconto.
As entradas XML são fixtures sintéticas baseadas nos dados visíveis da imagem fornecida; não são o XML oficial da nota, não têm assinatura e não devem ser transmitidas ao governo.
O canhoto é desligado por padrão. Situação cancelada/substituída vem da notem; todos os demais dados vêm do XML. Ausência é `-`; zero só aparece se estiver no XML.
Fonte Liberation Sans (equivalente métrico de Arial), incorporada com suporte a acentos. Logo original preservada em public/danfse/.
Os códigos cStat são traduzidos pelo TStat do XSD oficial. Os PNGs são exemplos de impressão, não confirmação de emissão real.

QA: primeira inspeção identificou rótulo IBS/CBS longo e canhoto sem divisórias verticais; composição ajustada para reservar altura dos rótulos e adicionar divisórias. Sete versões revisadas após nova renderização.
